# Judge demo script (2:40 target, under 3 minutes)

## Start clean and prepare the cold open

From the repository root:

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
set -a; source .env; set +a
python run_demo.py --no-browser
```

Open `http://127.0.0.1:8770`. For the cold-open comparison, click the plan chip and then the closure chip; start recording with that before/after result visible. It is generated by the local backend. Press **Reset demo** on camera before starting the timed replay. Then record the plan, closure, and outage chips in order. For another take, reset once and repeat. No API key, external LLM, or supplier call is needed. Stop both local services with Ctrl+C.

## Timed script

**0:00–0:15 — Lead with the payoff (pre-seeded real app state).** Show the simulated disruption card and read: “When Sagrada Família closes, RoamReady replans the city break and shows the tradeoff: the estimate moves from €1,712 to €1,638, and local travel from 159 to 127 minutes. This event and every estimate are simulated.” Keep the before/after cards and explicit direction labels visible.

**0:15–0:25 — Reset on camera.** Press **Reset demo**. The opening screen says what problem RoamReady solves: travelers want a personalized trip that can adapt when plans change. Identify the screen as a local Alexa+-style web simulation.

**0:25–1:00 — Build the original trip.** Click the plan chip: “Plan a four-day Barcelona trip for two under €1,800; we love architecture, art and food.” Show the four-day itinerary, `plan_demo_trip` MCP call, JSON arguments and structured result. Point to the estimate: €620 airfare + €480 lodging + €280 meals + €80 local transport + €252 activities = €1,712, leaving €88. Open **How the simulated costs are estimated** briefly.

**1:00–1:40 — Disruption and rescue.** Click the Sagrada Família closure chip. Show `rescue_demo_trip_tool`, before/after cards, removed attraction and replacements. Call out €74 less estimated spend (remaining budget €88 → €162) and 32 fewer estimated local-travel minutes (159 → 127). Reiterate that the closure is simulated, not a live alert.

**1:40–2:00 — Provider recovery.** Click the outage chip. Show the clearly labeled injected simulated 503 and offline recovery result. This test makes no provider/network request.

**2:00–2:35 — Prove the track technology and close.** Point to the visible activity trace and say: “The browser is a real MCP client: it initializes a Streamable HTTP session, lists tools, calls them, and renders structured results from our self-hosted server, which negotiates MCP 2025-11-25. This is not an Alexa device, private Alexa+ preview, live quote, or booking.” End on the measurable before/after result.

Use only project UI and narration; no third-party logos, footage, or music unless rights are confirmed. Upload the final cut publicly to YouTube or Vimeo and confirm it is shorter than three minutes.
