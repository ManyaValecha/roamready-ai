A FEW THINGS TO KNOW

Demo & help

RoamReady is a local travel planning demo that uses MCP tools for planning and recovery.

DEMO MODE

What’s simulated?

Barcelona attraction availability, opening hours, ticket costs, lodging, meals, airfare and local travel times are illustrative. Provider outage and landmark closure are simulated scenarios.

No booking, payment, current quote or live disruption feed is connected.

MCP CONNECTION

Planning through MCP.

The dashboard sends planning, saved-trip, profile and rescue requests through the Streamable HTTP MCP server. The app does not connect to an Alexa device or restricted Alexa+ preview tools.

http://127.0.0.1:8765/mcp
