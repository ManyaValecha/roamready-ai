# RoamReady AI — Three-Minute Demo

## 0:00–0:15 — The problem
Travel plans can break unexpectedly. A closed attraction or unavailable
provider can disrupt the whole itinerary, budget, and schedule.

## 0:15–0:40 — Plan
Request a four-day Barcelona trip for two, under EUR 1,800,
focused on architecture, art, and food.

Show the itinerary, budget, and estimated travel time.

## 0:40–1:15 — Disrupt
Trigger the reproducible attraction-closure scenario.

Show the original itinerary and identify the activity affected.

## 1:15–1:50 — Rescue
Run the rescue flow. Explain the replacement activity and why it fits
the user's interests and constraints.

## 1:50–2:20 — Compare
Show original versus rescued total cost, remaining budget, travel time,
activities changed, and trade-offs. Use actual computed values.

## 2:20–2:40 — Save and retrieve
Save the rescued plan and retrieve it to demonstrate persistence.

## 2:40–3:00 — Technical proof and close
Show the actual MCP tool execution or structured results, then state
what is simulated and what is live.

Use only flows that have been tested. Replace this timing if the actual
application requires different steps. Never describe simulated results
as live bookings, availability, or verified market prices.
